# FCSC 2023 The Colour of Magic

Vous êtes en possession d’une image disque contenant un message secret. Cette image utilise **un système de fichier inconnu** contenant **des fichiers dans un format inconnu**.

Grâce à vos relations, vous avez réussi à mettre la main sur une archive contenant des fichiers similaires mais pour un autre message. Vous savez également que **chaque fichier encode un caractère et l’emplacement de ce caractère** dans un message. Saurez-vous reconstruire les messages de cette archive, puis le secret contenu dans l’image disque ?

Il y a sept formats de fichier différents. Un exemple de signature est fourni pour le premier format. Il est compatible avec les outils *file* et *binwalk*. Un exemple partiel est fourni pour le second format.

L’archive contient :

Échantillons de fichiers pour chaque type (*datasets/*)
Exemple de signatures (*signatures.magic*)
L’image disque (*challenge.bin*)


Fichiers:
- [the-colour-of-magic.tar.xz](the-colour-of-magic.tar.xz)
